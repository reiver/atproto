AT-Protocol (ATProto) Services

the different types of servers that make up the ATProto network

by Charles Iliya Krempeaux

An AT-Protocol (ATProto) network is not one server. It is many servers, of many different types, run by many different people and organizations. Each type of server has its own job.

These different types of servers are called services.

For example, a Personal Data Server (PDS) stores users' data. Other types of services collect that data, index it, moderate it, and present it to people.

(Note that one server can play more than one role. For example, a PDS is usually also a space host.)

Here is a list of developer guides for ATProto services:

Index

A

  • AppView — turns the network's data into an application

F

  • Feed Generator — decides which posts go in a custom feed

L

  • Labeler — publishes signed labels about accounts and content

M

  • Managing App — decides who may read and write a “managed” permissioned “space” (proposal)

P

  • Personal Data Server (PDS) — hosts accounts, and their data

R

  • Relay — combines many firehoses into one
  • Repo Host — stores and serves users' records in permissioned “spaces” (proposal)

S

  • Space Host — answers for a permissioned “space” as a whole (proposal)
  • Space Mirror — an internal syncer that serves its copy of a permissioned “space” to an application's other services
  • Syncer — keeps its own copy of a permissioned “space” up-to-date (proposal)
